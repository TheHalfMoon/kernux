- post-merge workflow: `35433562616` — six jobs SUCCESS.

The daemon now:

1. consumes the bounded owner bootstrap from inherited stdin before endpoint creation/bind;
2. obtains operating-system peer credentials from `Stream::peer_creds()` for every accepted connection;
3. normalizes those credentials into `ObservedPeerIdentity`;
4. reads and parses the fixed authentication preamble before any KRP frame;
5. authorizes peer identity plus launch nonce;
6. only after successful authorization reads, parses, dispatches, and responds to the unchanged KRP probe.

Invalid bootstrap fails before listener creation and uses generic error text that does not echo nonce material. Wrong nonce, missing auth, malformed auth, unsupported auth version, peer mismatch, and peer-credential errors fail the connection closed without terminating the daemon or exposing KRP health/version metadata.

`probe_once` was adapted to send the authentication preamble before the existing KRP probe; there is no retained unauthenticated public probe path.
