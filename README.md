# Kernux

**One place where humans and AI agents get computer work done.**

Kernux is an open agent operating environment that unifies AI agents, browsers, computers, terminals, files, tools, and remote runtimes in one workspace.

> Status: architecture and execution planning. The repository is being bootstrapped from first principles before implementation begins.

## Product thesis

Kernux is not only a coding IDE, browser agent, or desktop automation tool. It is a provider-neutral operating environment where a task can move safely across agents, the web, local or remote computers, tools, and verifiers while preserving permissions, provenance, state, and evidence.

The intended experience is simple:

```text
Describe the outcome
        |
        v
Plan -> Execute -> Observe -> Verify -> Deliver
        |           |
        +-- agents -+
        +-- web ----+
        +-- computer+
        +-- tools --+
```

Canonical product, architecture, donor, security, and execution documents will live under `docs/canonical/`.
